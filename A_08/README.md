# Assignment 08: Keras Neural Network and CNN

## Overview
This directory contains the implementation of **Assignment 08** for **ECE 5831**. The assignment explores deep learning implementations using **TensorFlow/Keras** across two distinct computer vision and pattern recognition tasks:
1. Implementing a Two-Layer Multi-Layer Perceptron (`TwoLayerKeras`) to classify handwritten digits on the **MNIST** benchmark.
2. Building, training, and evaluating a deep **Convolutional Neural Network (CNN)** to perform binary image classification on the **Cats vs. Dogs** dataset.
