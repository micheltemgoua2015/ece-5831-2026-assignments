# Assignment 03: Perceptron Implementation of Logic Gates

## Overview
This repository folder contains the implementation and testing of basic logic gates (**AND**, **NAND**, **OR**, **NOR**, and **XOR**) built using single-layer and multi-layer perceptron concepts with **NumPy**.

The objective of this assignment is to demonstrate how linear threshold units (perceptrons) can model basic Boolean functions and how non-linearly separable problems (like XOR) can be solved using multi-layer networks combining lower-level logic gates.
